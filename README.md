# 🚀 Hybrid ATS System

A **full-stack MERN-based Applicant Tracking System (ATS)** designed to streamline hiring management.  
It allows:
- **Applicants** to view jobs, apply, and track their application progress.  
- **Admins** to manage job postings, monitor applications, and update statuses.  
- **Bot users** to simulate AI-assisted reviews and auto-screenings.

---

## 🧩 Tech Stack

**Frontend**
- React.js with React Router
- Context API (Auth management)
- Axios for API integration

**Backend**
- Node.js & Express.js
- MongoDB with Mongoose ORM
- JWT Authentication
- dotenv for environment configuration
- Swagger for API documentation
